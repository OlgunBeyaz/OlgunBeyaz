## Die Idee

Ein Roman besteht aus mehr als Text. Figuren, Schauplätze, Szenen und zeitliche Abläufe müssen zusammenpassen. MiraNovel bringt diese Bestandteile in einem gemeinsamen Arbeitsbereich zusammen.

## Im Mittelpunkt

| Bereich | Zweck |
| --- | --- |
| **Manuskript und Editor** | Kapitel und Szenen organisieren und Texte ausarbeiten. |
| **Corkboard und Outline** | Den Aufbau einer Geschichte aus unterschiedlichen Perspektiven betrachten. |
| **Figuren und Schauplätze** | Informationen zu den Menschen und Orten einer Geschichte festhalten. |
| **Timeline** | Den zeitlichen Ablauf einer Geschichte im Blick behalten. |
| **Dashboard** | Projektinformationen und Statistiken überblicken. |

MiraNovel wird aktiv weiterentwickelt. Funktionsumfang und Bedienung können sich während der Testphase ändern.

## Entwicklungsrichtung

Die folgenden Bereiche werden entwickelt oder erprobt. Sie sind keine Zusage für einen bestimmten Veröffentlichungstermin.

- **Szenen-Intelligenz:** Figuren, Orte und Zusammenhänge einer Szene leichter nachvollziehen.
- **Atlas:** Beziehungen zwischen Figuren und Schauplätzen sichtbar machen.
- **Dilek:** Wörter direkt beim Schreiben nachschlagen; ein türkisches Offline-Wörterbuch wird bereits erprobt.
- **Sprachunterstützung:** Deutsch, Englisch und Türkisch stehen im Fokus.
- **Export und Druck:** Manuskripte für die Weitergabe und Ausgabe aufbereiten.

## Technische Grundlage

MiraNovel verwendet **Rust**, **Tauri** und eine **Svelte-Oberfläche**. Die Entwicklung richtet sich auf Desktop-Systeme unter Windows, Linux und macOS.

## English

**MiraNovel is a desktop writing application for planning, organizing and writing novels.**

It brings manuscript editing, chapter and scene organization, character and location information, a corkboard, an outline, a timeline and project statistics into one workspace.

The application is in active development and is being tried by initial testers. Work also explores scene context, relationship views and **Dilek**, a dictionary component with a Turkish offline dictionary prototype.

The technical foundation is Rust, Tauri and Svelte. Desktop development targets Windows, Linux and macOS, with German, English and Turkish as the focus languages.

This is an **information and documentation repository**. Application source code and public downloads are not provided here.
